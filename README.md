# 🍃 RM ACNL Mod Menu

Panel táctil para **Animal Crossing: New Leaf** y **Welcome amiibo** en la 3DS
(plugin de Luma3DS). Versión **0.9.0-beta.1** — beta.

## 📱 Instalar con un QR (recomendado)

👉 **Abre la página del proyecto y escanea el QR: https://rmhomelab.github.io/RM-ACNL-Mod-Menu/**

1. Instala **Universal-Updater** en la consola.
2. Universal-Updater → **Settings** → **Select Unistore** → **Add new** → **Add with QR code**.
3. Escanea el QR de la página → elige **RM ACNL Mod Menu** → **Instalar RM ACNL Mod Menu**.
4. Rosalina (**L + abajo + SELECT**) → *Plugin Loader* → **Enabled** → arranca el juego.

Ábrelo con **ZL + ZR** o **stick C** (New 3DS / New 2DS) o **L + abajo** (3DS / 2DS).

> ⚠️ Haz copia de tu partida antes (Checkpoint o JKSM).

## 💾 Instalar a mano

Descarga el ZIP de la [última versión](https://github.com/rmhomelab/RM-ACNL-Mod-Menu/releases/latest)
y sigue su `LEEME.md`.

## 🎨 Haz tu propio tema

https://rmhomelab.github.io/RM-ACNL-Mod-Menu/temas/ — colores, fondos e iconos; sale
un QR para leerlo con la cámara desde el panel. Funciona en el navegador, no se
sube nada.
